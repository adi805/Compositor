# Compositor.Windows v0.3.0

Windows port of [robbietilton/Compositor](https://github.com/robbietilton/Compositor)
(the macOS Swift app). Self-contained win-x64 build: unzip, run `Compositor.App.exe`.
No .NET install needed. `Compositor.App.exe --smoke` runs the headless render check.

## What works in this build

- Document model, layers panel, brush painting with per-stroke undo/redo
- `.comp` project round-trip (v0.1 and v0.2 files still open)
- Filters: Gaussian / Motion blur, Add Noise, Lens Correction, Grain (bit-exact C kernels)
- IO parity: import (PNG / JPEG / GIF / BMP / ICO / WebP, drag-and-drop from Explorer),
  export PNG (with `pHYs` DPI) and JPEG (quality slider, matte colour, JFIF density),
  96 px import thumbnails, 100 MP import budget
- Layer transform is honoured when rendering: what you see on canvas is what the PNG/JPEG
  export contains (flip, rotate, scale, translate)
- Canvas limits match upstream `DocumentLimits`: 30,000 px per side, 200 MP per surface,
  document budget `min(800 MP, max(200 MP, RAM/16))`

## Honest gaps

`docs/PARITY.md` is the contract: every upstream source file is a row with a status.
Not done yet, and listed there rather than hidden:

- Transform overlay drag handles (typed scale/rotate works, but no on-canvas handles)
- Downsample cache and tiled layer renderer (large-canvas performance)
- TIFF and HEIC import (unverified whether the pinned Skia build decodes them)
- Automatic update check (upstream uses Sparkle; no Windows equivalent wired up yet)
- Remove Background / content-aware fill: the ONNX subject-model path is proven to load
  and run, but the mask subsystem it needs is not built, so the menu entries stay disabled
- Layer masks, per-band Hue/Sat spectrum UI, feather / expand / contract selection

## Verification

The zip's `SHA256SUMS` is the only way to check a download: the packaging toolchain is not
byte-reproducible, so rebuild-and-compare is not a valid check.

CI runs on every push to `main`: Core tests, App tests, and the headless smoke render.
